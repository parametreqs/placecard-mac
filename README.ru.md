# PlaceCard для Mac

Открытое приложение для считывателя **IronLogic Z-2 RD_ALL**: считывает номер карты и вводит его в **Заметки** или другое активное приложение. Поддерживает перестановку байтов, вычисления, ведущие нули, десятичный и шестнадцатеричный формат, а также регистрацию карт в вашей таблице Nextcloud.

[**Скачать приложение**](https://github.com/parametreqs/placecard-mac/releases/latest) · [Полная инструкция на английском](README.md) · [Сообщить о проблеме](https://github.com/parametreqs/placecard-mac/issues)

## Установка

1. Скачайте **PlaceCard-Mac-arm64.zip**, распакуйте и перенесите **PlaceCard Mac.app** в папку «Программы».
2. Откройте приложение. Сборка подписана локально и не нотарифицирована Apple. Если macOS блокирует запуск и вы доверяете проекту, следуйте [инструкции Apple](https://support.apple.com/ru-ru/102445) для разрешения запуска именно этого приложения. На управляемых компьютерах эта возможность может быть недоступна.
3. Подключите Z-2 RD_ALL, выберите считыватель или порт `cu.usbserial…` и нажмите **Start reading**. Закройте другие программы, использующие этот порт.
4. Поднесите карту. На вкладке **Number format** выберите нужный формат. Режим **Mifare: Auto (4-byte hex / 7-byte decimal)** автоматически сохраняет четырёхбайтные карты в hex, а семибайтные переводит в совместимый с Windows десятичный номер. После обновления выберите Auto один раз; для новых установок он включён по умолчанию. Оставьте **Output: Keep source**. При выборе Auto дополнительные преобразования сбрасываются. Сравните результат с вашим Windows-приложением.
5. На вкладке **Typing** разрешите приложению доступ к управлению компьютером через **Enable Accessibility…**. В протестированной macOS 27 нужный раздел называется **Device Control and Data Access**. Затем включите **Type card numbers into the active app**.
6. Поставьте курсор в Заметках, уберите карту и поднесите её снова. **After number** позволяет добавить Return или Tab.

Совместимость сборки: **Apple Silicon M1–M5, macOS 14+**. Проверено на M4 с macOS 27 и Z-2 RD_ALL с прошивкой 230. Остальные модели Mac, версии macOS, типы карт и прямое USB-подключение требуют проверки на реальном оборудовании. Сборки для Intel пока нет. Приложение не записывает карты и не обновляет прошивку считывателя.

## Nextcloud — по желанию

Для регистрации нужен открытый в **Brave** файл `.xlsx` в **Nextcloud / ONLYOFFICE**. Сервер и таблица не заданы заранее.

- **Workbook…**: укажите HTTPS-ссылку на конкретный файл с его числовым ID и точное имя файла.
- Активный лист должен содержать печатный номер из четырёх цифр в столбце **A**, считанный номер в **B**, и хотя бы одну существующую запись.
- **Check workbook** проверяет чтение таблицы. Затем включите автоматическую регистрацию, считайте карту и введите её четыре печатные цифры.
- Приложение проверяет оба номера на дубли, добавляет новую строку, сохраняет ведущие нули и запрашивает сохранение. Проверьте статус сохранения в редакторе.

Во время операции не переключайте фокус и не вводите текст. Работайте с одним оператором регистрации: браузерная автоматизация не гарантирует уникальность при одновременном редактировании. При ошибке частично записанную строку нужно проверить перед повтором. Лимит — 10 000 используемых строк. Полные ограничения, сборка из исходников и тесты описаны в [README.md](README.md).
